# Learning: Context Menus

## Contexts

The `contexts` array determines when your menu item appears:

| Context | Description |
|---------|-------------|
| `all` | All contexts |
| `page` | Page context |
| `selection` | Text selection |
| `link` | Links |
| `image` | Images |
| `video` | Videos |
| `audio` | Audio |
